## P0 短期（建议下一批就做）

### 1. 划词历史 + 生词本/收藏

- **描述**：结果面板加 ★ 收藏与 🕐 历史入口；本地 SQLite 记录（原文、动作、结果、来源应用、时间），收藏带"生词本"标记
- **价值**：M3 知识库飞轮的最小闭环；让用户感知"拾趣记住了我"
- **技术**：SQLite（`rusqlite`）单表，**表结构直接带知识库字段**（主题标签、上下文快照），后续 M3 零迁移；历史列表面板复用结果面板容器
- **依赖**：无新权限

### 2. 朗读 TTS ❌ 已否决（2026-09，曾实现后移除）

- **否决理由**：系统音色质量与语速体验不佳（AVSpeechSynthesizer 免费音色机器感重）；用户价值评估不成立——划词阅读的核心诉求是"理解"而非"听"。若未来重启，前提是接入更自然的音色源（如高质量云端 TTS）
- **备注**：实现期间顺手修复了 wry 上游崩溃（#1752，nil URL 导致进程 abort），该修复以 vendor 补丁形式保留（`vendor/wry` + `Cargo.toml` 的 `[patch.crates-io]`），与 TTS 无关

## P1 中期（并入 M2 主线）

### 4. 结果面板内追问（AI 问一问的落地形态）

- **描述**：流式结果下方内联输入框，直接针对结果多轮追问（"再举个例句""换个说法"）
- **价值**：多轮对话藏在最高频的触点里，比独立入口转化率高得多；M2「问一问」的落地形态建议就是它
- **技术**：动作注册表加 `followup` 类动作；会话历史保存在面板 state（不落库）

### 5. 截图 OCR 划词

- **描述**：快捷键拉起框选 → 系统 OCR → 走同一条浮动条链路
- **价值**：覆盖视频字幕、图片、扫描 PDF 等"选不中"的场景
- **技术**：`CGWindowListCreateImage`/ScreenCaptureKit + `Vision.framework`（macOS 自带，中文效果好）
- **依赖**：屏幕录制权限（新）；自检页加第三项权限检测

### 6. 上下文划词

- **描述**：解释类动作自动附带选区周边段落（静默，用户无感），翻译不附加
- **价值**：解释质量质变（同一个词在不同语境含义不同）
- **技术**：AX 读 `AXSelectedText` 周边文本（部分应用拿不到则优雅降级为无上下文）；prompt 模板加 context 段
- **依赖**：无

### 7. 自定义动作 + 模板分享

- **描述**：用户写自己的动作（名称 + prompt 模板 + 图标），支持 JSON 导入导出
- **价值**：进阶用户粘性；模板分享 = 社区增长点（动作市场雏形）
- **技术**：动作注册表本就支持运行时注册；模板 = `{name, prompt, model?}` 的 JSON
- **依赖**：无

## P2 后续储备

### 8. 段落级理解模式

- **描述**：选中一整段 → 「全文综述 + 术语表 + 中英对照」三段式模板
- **价值**：阅读场景的杀手动作；与逐词划词互补
- **技术**：动作注册表新动作 + 结果面板分栏模板

### 9. 生词间隔复习（Anki 式）

- **描述**：生词本词条按遗忘曲线每日推卡（菜单栏浮层，一分钟复习三五个）
- **价值**：把工具变成学习习惯，留存抓手
- **技术**：依赖 #1 的收藏数据；SM-2 简化版调度
- **依赖**：#1

### 10. 复制格式选项

- **描述**：复制为 Markdown / 纯文本 / 带原文对照
- **技术**：复制菜单项 + 格式转换，纯前端

### 11. 面板字号三档调节

- **描述**：小/中/大三档，设置页与面板快捷键均可调
- **技术**：CSS 变量 `--fs-base` 切换

### 12. 取词成功率透明化

- **描述**：自检页展示最近 N 次划词统计（AX 成功 / 兼容模式 / 失败）
- **价值**：兜底透明化，建立信任；也是排查问题的用户侧工具
- **技术**：捕获线程埋点计数进 settings 内存态

### 13. 阅读轨迹 / 统计

- **描述**：今天划了什么、主题分布、阅读时长——知识库的入口叙事
- **技术**：依赖 #1 数据 + 简单聚合页
- **依赖**：#1
