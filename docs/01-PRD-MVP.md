# 拾趣 (Magpie) · 产品需求文档 — MVP (M1)

> 版本 v0.1 · 2026-09 · 状态：已评审（对话评审）

## 1. 一句话定位

**拾趣**：划词即理解的 AI 阅读伴侣。在任何应用里选中文字 → 浮动条即时提供 AI 搜索/翻译/解释/问答，未来把每一次理解沉淀为个人知识库。

## 2. 背景与差异化

- 纯翻译划词工具（Bob / Pot / Easydict）已充分竞争，纯工具无留存。
- ima 类知识库以"文档"为中心，要求用户主动上传，门槛高。
- **拾趣的差异**：以「划词/阅读轨迹」为中心——零成本捕获（无障碍 API 优先）+ 带上下文理解 + 未来"划词即收藏"的知识库飞轮（M3）。

## 3. 目标用户（MVP 聚焦"阅读与学习"场景）

| 优先级 | 人群 | 核心场景 |
|---|---|---|
| P0 | 研究者/学生/知识工作者 | 读外文资料、行业报告、文献时划词理解 |
| P1 | 大众用户 | 新闻生词、概念查询、日常阅读理解 |

> 产品边界：**不做程序员向功能**（报错解释、代码解释等）——聚焦阅读与学习场景，避免与开发者工具赛道正面竞争。

MVP 通过 **BYOK**（用户自带 API Key）服务动手能力强的种子用户，验证核心交互后再上官方托管（M4+）。

## 4. MVP（M1）功能范围

### 4.1 核心链路（P0）

1. **划词捕获**（macOS）
   - 全局监听鼠标：拖选（位移 > 6px）或双击选词后触发
   - 通过无障碍 API（AX）读取选中文本与鼠标位置；不支持取词的应用自动走「兼容模式」兜底（模拟 ⌘C，自动还原剪贴板）
   - 松手后 200ms 防抖；同一选区不重复触发
   - 未授权辅助功能时：引导页 + 一键打开系统设置 + 划词自检
2. **浮动条**
   - 出现在鼠标附近，自动防出屏；毛玻璃胶囊样式，支持明暗主题
   - 动作按钮：**翻译｜解释｜总结**（MVP 三个，架构上为动作注册表，可扩展）
   - 点击动作 → 浮动条下方内联展开结果面板，**流式**渲染
   - 消失条件：点击空白处 / Esc / 打开新选区
3. **AI 服务**
   - BYOK 设置：OpenAI 兼容协议（预设 DeepSeek，可填任意 base_url + key + model）
   - 流式输出；动作各自独立 prompt 模板
4. **主窗口**：设置（Provider 管理）+ 划词自检（权限状态/检测指引）+ 关于

### 4.2 工程细节（P0）

- 按应用黑名单：终端、密码管理器等不触发（MVP 提供配置文件级支持，GUI 管理 M2）
- 自身窗口（主窗口/浮动条）内选词不触发
- 捕获失败静默处理（不弹错误提示）

### 4.3 明确的非目标（MVP 不做）

- Windows 版捕获（M2，架构已预留）
- ~~剪贴板兜底（坚持无痕划词；未来作为默认关闭的高级选项再议）~~ 已落地为「兼容模式」（常开兜底，见 ADR-05 修订）
- AI 搜索 / 问一问多轮 / 知识库 / 收藏（M2/M3）
- 官方托管模型、账号体系、付费（M4）
- 常驻托盘、全局快捷键呼出（M2）
- 带"选区周边上下文"的深度理解（M2，依赖 AX 深化）

## 5. 验收标准（MVP DoD）

- [ ] macOS 13+ 在 Safari / Chrome / 备忘录 / VS Code / 微信 中拖选与双击均能弹出浮动条
- [ ] 松手 → 浮动条出现 ≤ 300ms（本地处理，不含 AI 首字）
- [ ] 点击翻译 → 首字上屏 ≤ 2s（DeepSeek 正常网络下）
- [ ] 辅助功能未授权时，自检页能正确识别并一键跳转系统设置
- [ ] 黑名单应用内划词不弹出；自身窗口内划词不弹出
- [ ] AX 取词成功时不读/写剪贴板；兼容模式取词后自动还原剪贴板快照
- [ ] 常驻内存（不含 AI 请求时）< 120MB

## 6. 成功指标（发布后 4 周内测）

- 划词→动作点击转化率 > 40%
- 日均划词次数/活跃用户 > 15
- D7 留存 > 25%（种子用户群）
