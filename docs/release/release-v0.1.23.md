## Added（新增）

- [x] Anki 一键建卡（2026-11-15）：连接本机 Anki（AnkiConnect 插件）后，胶囊与结果窗
  出现「Anki」动作——划词即建卡进默认牌组，正面为选中文本；结果窗建卡时背面存当前
  动作的结果（翻译/解释/总结），胶囊直建背面留空；标签按天聚簇（magpie + 日期）。
  ⌄ 菜单可手动指定卡片类型（不指定则按划词长短自动选卡；主按钮默认卡型可配——
  设置页新增「主按钮默认卡型」自动/单词卡/内容卡三档，默认自动；配套类型仅
  一种时不受影响，⌄ 临时指定仍优先）。零配置主路径：设置页
  打开即自动检测连接，「创建 Anki 集合」一键完成（用户触发）——牌组「拾趣」（含
  单词卡/内容卡两个子牌组）+ 两种配套笔记类型（单词卡查词居中大字、内容卡摘录
  长文换行），自动带来源/链接/日期；自定义笔记类型建卡智能兜底。重复卡片有明确
  提示，Anki 未启动时提示连接失败。背面与结果窗渲染决策一致后入卡（2026-11-17：
  AI 输出按 markdown 渲染，粗体/列表/代码块在 Anki 里正常显示而非源码符号；
  机器翻译按纯文本，与面板一致；配套卡型出厂样式随之补强，已有卡型在连接检测时
  静默升级样式，用户改过卡型则不动）。
  验收：一键创建→划词建卡→Anki 中可见正面/标签，卡片样式干净无残留字段；
  结果窗建卡背面为对应动作的结果且渲染与结果窗一致（AI markdown 正常显示、
  机器翻译纯文本）；重复与未启动提示正确；未配置时动作不出现；老安装连接后
  卡型样式自动补强、自定义过卡型的集合不受影响。

## Fixed（修复）

- [x] 划词胶囊收起不及时（2026-11-15）：在取词会失败的应用（AX 桥间歇瘫掉的
  Electron 系，如 ZCode）里连续做划词手势时，每次失败手势会阻塞事件处理 5 秒+，
  期间点空白/Esc 收胶囊全部排队延迟——胶囊要等好几秒才消失。验收：在失败手势
  之后立刻点空白或按 Esc，胶囊立即收起；正常划词弹出与取词成功率不受影响。
- [x] Anki 连接失败按安装状态分层提示（2026-11-18）：发往 127.0.0.1 的请求禁用
  系统代理——此前代理会截胡本机请求，「Anki 未启动」的连接被拒被伪装成代理的
  HTTP 502，且裸状态码直接暴露给用户。连接失败时探测 Anki 安装状态分层提示：
  应用未安装 → 「请先安装 Anki 应用」；已安装 → 「Anki 未启动——打开 Anki 后
  重试（首次使用需安装 AnkiConnect 插件）」。真实错误细节进日志。
  验收：未安装 Anki 时检测显示安装引导；已安装未启动时显示启动引导；
  开启系统代理不再出现 502。
