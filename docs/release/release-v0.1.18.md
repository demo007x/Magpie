## Fixed（修复）

- [x] 结果窗「更多」胶囊堆及其行侧 chips 需点一下窗口才有 hover（2026-10-27
  用户反馈；与早先存入目标 chips 同病）：非 key 窗口原生 :hover 不渲染，合成
  hover 候选链漏了 .rail .pitem，CSS 也缺 .syn-hover 变体。补齐后光标划上
  即蓝底白字；弹出瞬间的 hover 挂起规则同步覆盖（压制时回落墨底而非透明）。
  验收：识图结果窗不点击，hover ⌃N 堆里的胶囊与笔记/任务/卡片均即时高亮
- [ ] 钉图仍比原图轻微发虚（2026-10-27 用户反馈；半像素修复之上的第三层
  根因）：图片的发丝描边用 border 画，全局 border-box 下 border 吃进内容
  区——整张图被不可见的 0.2% 重采样（尺寸看不出变、锐度整张损失）。改用
  box-shadow 画描边（布局零占位）；另滚轮缩放贴近 100% 时自动吸附回 1:1，
  防触控板微滑把缩放带到 0.998 这类重采样值。验收：钉图与原图清晰度一致，
  触控板轻扫缩放后回到 ±2% 内自动回 100%
- [ ] 钉图比原文区预览糊（2026-10-25 用户反馈）：钉图窗口的位置与尺寸落在
  半像素边界时，图片每个像素横跨两个物理像素，WebKit 对整图插值模糊。
  修复 = 窗口尺寸/位置与图片元素尺寸全部吸附物理像素网格（缩放/拖拽后
  同样吸附）。验收：@2x 屏钉图与原文区预览清晰度一致
- [ ] 钉图只能钉一次（2026-10-25 用户反馈）：关闭钉图后同一识别结果再点
  「钉图」无反应。根因是钉图按「消费式取走」设计——第一次钉图拿走原图
  所有权，关闭钉图时连临时文件一起删除，第二次取不到。改为复制不消费：
  同一识别结果可反复钉、可同时钉多颗，每颗钉持有独立副本，互不影响。
  验收：识别后钉图 → 关闭 → 再钉（可多颗），图片均正常出现
- [ ] 暗色主题下浮动条/二级浮层残影（2026-10-25）：卡片收起/移位后让出的区域
  残留上一帧内容（灰色空面板、旧胶囊轮廓）。根因是暗色材质的颗粒层用了
  `mix-blend-mode: overlay`，在 macOS 26 的 WKWebView 透明窗上触发合成器
  残帧（wry#1848 同类）；亮色主题从无颗粒层故从不复现。移除颗粒层后消失。
  验收：暗色模式反复展开/收起/切换二级菜单，无任何残留影像
- [ ] 复制验证码误触发（2026-10-24 用户反馈）：终端日志等长文本里的任意 4-8 位
  数字（pid/端口/编号）都会顶出「复制验证码」。改为语境三分规则——精准选中数字
  本身或极短选区照旧识别；更长文本必须出现「验证码/校验码/code/OTP」类关键词且
  数字与关键词同句邻近，否则不触发。验收：划选终端日志不出现验证码动作；划选
  短信类文本（含验证码字样）正常出现且复制值正确


- [x] 验证码误报：日期时间片段与 #编号覆盖的数字不再误识别为验证码
  （"北京#001 / 10月31日 10:00-19:00" 曾漏出 00110/3110 类碎片候选）。
  验收：划选含日期、时间、#编号的文本，验证码组不再出现其中的数字碎片
