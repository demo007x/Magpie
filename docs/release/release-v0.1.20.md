## Added（新增）

- [x] 截图胶囊：识图取字框选在自绘遮罩上完成——触发即全屏变暗、拖出选区
  （蓝色描边实时跟随）、松手静默截图，遮罩原位无缝切换为会话模式（选区框与
  截后遮罩同一窗同一视觉，无系统框选段的闪变）；胶囊浮在选区右下角，四件套
  （识别文字/翻译/解释/总结）点选后才进识别管线；选区可拖动（胶囊实时跟随，
  拖动后执行按新矩形重截当前屏幕）；点选区外/误触取消并清理截图；
  识图翻译/解释/总结快捷键同走此框选，松手后立即识别执行。
  验收：触发识图取字立即变暗无闪变，框选后胶囊出现在选区右下角（贴边翻
  上方、不出屏），点「识别文字」出结果面板，点翻译/解释/总结自动执行，
  拖动选区胶囊跟随且执行按新位置识别，取消不残留提示；全程主窗口不出现
  （会话期隐藏，结束保持隐藏，需要时从托盘/程序坞打开）
- [x] 选区边缘拖拽缩放（2026-11-04 需求）：光标贴近选区边/角（8px 热区，
  边线内外都算）变缩放游标，按住拖动即缩放——对侧边锚定、最小 8px、
  钳在本屏内；缩放中胶囊实时跟随，执行动作按缩放后的矩形重截。
  验收：光标放到边/角变对应缩放游标，拖动缩放顺滑、胶囊跟随，
  缩到 8px 下限不再缩小，缩放后点动作按新矩形识别

  验收：设置页说明与实际交互一致，且为一行内最短表述
