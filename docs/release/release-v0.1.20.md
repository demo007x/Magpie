# release-v0.1.20

- 状态：开发中
- 主题：截图胶囊（框选后选动作再识别）+ 多显示器结果窗落屏
- 说明：三板块条目均为 checkbox，提出时记入、落地即勾选；CHANGELOG 于发版时从
  本文件已勾选条目生成（见 AGENTS.md 发版清单），本文件只记需求与验收，不写实现细节

## Added（新增）

- [x] 截图胶囊：识图取字框选在自绘遮罩上完成——触发即全屏变暗、拖出选区
  （白环实时跟随）、松手静默截图，遮罩原位无缝切换为会话模式（选区框与
  截后遮罩同一窗同一视觉，无系统框选段的闪变）；胶囊浮在选区右下角，四件套
  （识别文字/翻译/解释/总结）点选后才进识别管线；选区可拖动（胶囊实时跟随，
  拖动后执行按新矩形重截当前屏幕）；点选区外/误触取消并清理截图；
  识图翻译/解释/总结快捷键同走此框选，松手后立即识别执行。
  验收：触发识图取字立即变暗无闪变，框选后胶囊出现在选区右下角（贴边翻
  上方、不出屏），点「识别文字」出结果面板，点翻译/解释/总结自动执行，
  拖动选区胶囊跟随且执行按新位置识别，取消不残留提示
- [x] 选区边缘拖拽缩放（2026-11-04 需求）：光标贴近选区边/角（8px 热区，
  边线内外都算）变缩放游标，按住拖动即缩放——对侧边锚定、最小 8px、
  钳在本屏内；缩放中胶囊实时跟随，执行动作按缩放后的矩形重截。
  验收：光标放到边/角变对应缩放游标，拖动缩放顺滑、胶囊跟随，
  缩到 8px 下限不再缩小，缩放后点动作按新矩形识别

## Changed（变更）

- [x] 快捷键页「识图取字」说明对齐截图胶囊流程（2026-11-04）：旧文案是
  "框选即识别"，实际已是框选 → 动作条（识别文字/翻译/解释/总结）选动作
  再识别。改为"框选屏幕任意区域，松手弹出动作条，选动作后识别；结果可
  复制、钉住原图"。识图翻译/解释/总结三行未动（立即执行的描述仍准确）。
  验收：设置页说明与实际交互一致

## Changed（变更）

- [x] Windows 框选流程对齐截图胶囊（2026-11-04）：此前 Windows 是"框选松手
  立即识别"——没字直接弹错、无动作选择。对齐 macOS 截图胶囊流程：框选松手
  后弹动作胶囊（识别文字/翻译/解释/总结），选动作才识别；"未检测到文字"
  从框选阶段挪到识别阶段（框选本身永不报错），失败时保留截图留证。
  helper 新增只截屏模式（截图与识别分离）；本轮不含选区拖动/缩放（Windows
  遮罩窗无会话段，后续对齐）。取消 = 点击胶囊外任意处。
  验收：Windows 上 Ctrl+S 框选后出现动作胶囊，选动作出结果；空白区域框选
  后点「识别文字」才提示未检测到文字，点击胶囊外取消

## Fixed（修复）

- [x] 结果窗 markdown 渲染失效（2026-11-04 用户反馈）：先跑过机器翻译
  （百度/DeepL 等纯文本服务）再切到解释/总结等 AI 动作，翻译留下的
  纯文本渲染标志未清除，AI 输出的 markdown 被按原文显示。
  修复 = AI 动作起跑与缓存命中时显式清除该标志。
  验收：同一面板先识图翻译（机器翻译）再点解释/总结，markdown 正常渲染；
  机器翻译本身仍按纯文本显示

- [x] 胶囊动作高亮挂死（2026-11-04 用户反馈）：鼠标划出胶囊后，最后 hover
  过的动作一直亮着选中色不消失——划词胶囊与结果窗动作行都有。
  修复 = 光标离开窗口/全部 hover 目标的边沿上摘除合成 hover 高亮
  （此前离开只记收起时刻、不摘类，而移除类的事件只在命中目标窗口时才发）。
  验收：hover 任意动作后把鼠标移开（桌面/另一胶囊/截图遮罩），高亮立即消失；
  移回来恢复 hover 反馈

- [x] 多显示器下结果窗截半/跑错屏（2026-11-04 用户反馈）：结果窗此前按主屏
  定位与钳制，在副屏上划词/识图时窗口落到主屏右缘或被推出屏外一半
  （缩放比例非 2x 的屏上更甚）。
  修复 = 落屏跟随操作发生的屏：划词贴胶囊所在屏、识图贴框选所在屏、
  记忆位置锚定其所在屏；钳制改用所在屏可见区域，窗口尺寸换算不再写死缩放系数。
  验收：多显示器（含不同缩放比例）下划词与识图，结果窗完整出现在操作屏内；
  拖过位置的记忆行为不变（记忆屏断开时回退主屏）
