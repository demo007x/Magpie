## Added（新增）

- [x] 朗读音色包（2026-11-10）：设置页新增「朗读」——引导下载本地音色包
  （Kokoro 中英双语 ONNX，约 410MB，装完离线可用），下载后可逐个试听、
  设定中英文各自的默认音色。macOS 与 Windows x64 均支持。验收：未安装时
  只有下载按钮与进度；装完出现中英文音色列表，点试听能出声、再点停止，
  点选即成为默认音色。
- [x] 朗读入口（2026-11-10）：结果窗加朗读钮，读当前展示的文本（划词原文 /
  翻译译文），再次点击停止。验收：点朗读开始读、再点停止；划词与译文均可
  朗读，中英文自动选对默认音色；朗读期间不阻塞界面交互
- [x] 长文分块朗读（2026-11-10）：超过一块的文本按句切分、逐块合成播放，
  首块短以保证尽快出声，后续块长以保证块间不留空档。验收：朗读一段 300 字
  以上的解释，1-3 秒内出声、全程无明显停顿；中途点停止/切动作/关窗立即静音
- [x] 朗读开关（2026-11-10）：不需要朗读的用户可在设置 › 朗读里关闭功能，
  关闭即自动卸载音色包（删除引擎与模型，约 320MB）并隐藏结果窗朗读图标；
  重新开启后重新下载即恢复。验收：关闭后朗读图标消失且磁盘空间释放；
  重新开启并下载后功能恢复、音色偏好保留
