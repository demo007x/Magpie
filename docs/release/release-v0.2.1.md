## Added（新增）

- [x] 全局快捷键可单独清除（issue #26）：识图取字、识图翻译、识图解释、识图
  总结、访达选图取字五项，各自多一个「清除」，保存后不再占用该组合键，避免
  与其他软件冲突。清除后显示「未设置」，点「重置」回到默认键位或重新录制即可
  恢复。清除只解除快捷键，托盘菜单里的功能入口照常可用。
  验收：清除任一项并保存后，该组合键不再触发；其余快捷键不受影响；托盘菜单
  该项不显示键位、点击仍能触发；重启应用后仍为「未设置」。

- [x] 识图识别出的表格保持 Markdown 格式：识别文字与翻译/解释/总结的原文
  提取，表格输出为 Markdown 表格（此前是制表符分隔的散文字）；模型的分隔线
  列数与表头不齐时自动修正（列数不齐的表格任何软件都解析不出，实测发生过）。
  结果窗里表格默认渲染成表格（带「编辑原文」切换，改字仍走原始文本），复制、
  存进 Obsidian 的是可直接成表的 Markdown 文本。
  验收：开启识图配置后框一张表格，结果窗渲染出表格（列数与原图一致，含行号
  列）；点「编辑原文」看到并可改 Markdown 源文本；复制、存 Obsidian 的表格在
  Obsidian 里正常成表；表格截图点「朗读」不读出竖线和横线。

- [x] 识图结果存 Obsidian / Anki / 日历带上网页链接（识图场景补齐划词已有的
  能力）：框选识图时记下当时的前台应用，识别结果存笔记、建卡、加日历时据此
  反查页面 URL。此前识图结果永远没有来源链接，图里的文字脱离网页后难以回溯
  出处。仅网页场景有链接，其他应用识图为空，与划词行为一致；文件选图与钉图
  再识别不带来源。
  验收：在浏览器网页里框选一张含文字的图识别，存 Obsidian 后笔记带 {link}；
  桌面应用里同样操作无链接（不误报）；文件选图无链接。

- [x] 结果窗渲染数学公式：识图与 AI 结果里的 LaTeX 公式（$…$ 行内、$$…$$
  独立行）直接排版成公式（KaTeX，本机离线渲染），不再显示源码。识别原文含
  公式或表格时默认渲染（可切「编辑原文」改 LaTeX 源码）；识别提示词明确公式
  用 LaTeX 输出；复制得到的是 LaTeX 源码（可粘进 Word / Markdown / Anki）；
  含公式的识别结果点「朗读」不读 LaTeX 命令；存 Anki 的卡片公式由 Anki 自带的
  MathJax 渲染（卡片不依赖本应用样式）。
  验收：框一张含公式的图识别，结果窗直接显示排版后的公式（积分/分式/上下标
  正确）；「编辑原文」里是 LaTeX 源码可改；复制得到 LaTeX；存 Obsidian 的公式
  在 Obsidian 里正常渲染（Obsidian 原生支持 $…$）；存 Anki 后卡片里公式正常；
  含「价格 $5 另一件 $10」的普通文本不误判为公式。

- [x] 识图没认出字时给出正确提示：模型看图说「没有文字」时不再把这五个字
  当成识别结果展示，而是自动转一遍本机识别（模型看走眼而本机认得出时照样
  出结果），两头都没有才在结果窗给出「没有认出文字，换一张更清晰的图试试」
  与可点的「重试」。此前屏幕上会出现一行「未识别到文字」，看着像图里的内容，
  也不走任何失败提示。结果窗的重试按钮同时修复了识图取字失败时点了没反应
  的问题（此前只在有动作时才响应）。
  验收：对无文字的图片开启识图取字，结果窗显示新话术与「重试」，不再出现
  裸的「未识别到文字」；点「重试」重新识别；框一张真有文字的图行为不变。

- [x] 结果窗原文/结果分割线可拖动：结果模式下按住原文区下边线上下拖动，
  分割线跟着光标走（上拖原文减矮、下拖原文增高），窗口总高不变、只改原文
  与结果的高度分配，双向钳制。悬停时边线染品牌色提示可拖（不新增线条）；
  拖过的高度本会话保持，chevron 点折叠/展开或双击分割线回到 75px/220px
  两档预设。
  验收：分割线跟随光标移动、拖动即时无滞后；拖动后原文/结果高度随之变化、
  窗口尺寸不动；按住分割条不会拖动整个窗口；原文文字选择、结果滚动、贴底
  跟随不受影响；chevron/双击回预设。
