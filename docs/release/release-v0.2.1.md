## Added（新增）

- [x] 全局快捷键可单独清除（issue #26）：识图取字、识图翻译、识图解释、识图
  总结、访达选图取字五项，各自多一个「清除」，保存后不再占用该组合键，避免
  与其他软件冲突。清除后显示「未设置」，点「重置」回到默认键位或重新录制即可
  恢复。清除只解除快捷键，托盘菜单里的功能入口照常可用。
  验收：清除任一项并保存后，该组合键不再触发；其余快捷键不受影响；托盘菜单
  该项不显示键位、点击仍能触发；重启应用后仍为「未设置」。
