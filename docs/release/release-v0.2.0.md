## Added（新增）

- [x] 应用内一键更新（2026-11-19，ADR-11 翻案「只提示不自更新」）：发现新版本后
  toast 与弹窗各提醒一次，弹窗确认即下载安装并重启，全程不用去 GitHub 手动下载；
  更新说明（与发布页同源的版本说明）直接内嵌在弹窗里，不用跳转；更新后 macOS
  三项授权（辅助功能/输入监控/屏幕录制）不再重置；「稍后」不打扰但下个版本会
  再提醒。通用页新增「自动检查更新」开关（默认开）：只控制后台自动检查，
  应用运行期间每小时巡检一次（网络检查受 24h 节流），关闭后仅关于页手动
  检查与更新不受影响。托盘右键菜单新增「检查更新」：即点即查，发现新版
  直接打开应用弹窗（含内嵌说明），无新版/失败即时 toast 反馈。
  ⚠ 发版链路依赖：更新包 minisign 签名 + macOS 稳定签名身份（自签证书 secrets）+
  Release 挂 latest.json，三者缺一更新静默失败（AGENTS.md 发版清单 ④）。
  验收：旧版本应用内收到新版提示 → 弹窗显示版本对比与进度 → 确认后自动重启进
  新版；关闭开关后启动不再检查、关于页手动检查正常；「稍后」同版本不再弹。

- [ ] 识图的「识别文字/翻译/解释/总结」可改由模型直接看图处理（2026-11-19）：
  AI 服务新增「识图配置」子页，按四个能力分别开关，默认全关（行为与之前完全
  一致）。开启后不再先本机识别，模型直接读截图输出结果；识图取字的识别文本
  流式写入原文区（识别过程中显示进行中提示，不再弹「正在识别」全局 toast，
  识别原文照旧可编辑）。识图动作（翻译/解释/总结）由模型一次请求完成提取
  原文与执行任务，原文实时回填结果窗原文区（可编辑后重跑动作），结果区
  展示任务输出。前提是「模型」页已配置默认模型服务；未配置服务或请
  求失败（结果尚未开始输出）时，自动改用本机识别，用户无感知中断。验收：开
  启开关 + 已配置的服务，框选后结果由模型流式输出（图
  表、排版复杂的内容表现优于本机 OCR）；断网或换不支持图片的服务时结果窗
  仍能出本机识别文本且可钉图；全关时回归原链路。

## Fixed（修复）

- [x] 关于页「已是最新」提示从不显示（2026-11-19）：前端把检测结果状态串认成
  `current`，后端实际返回 `upToDate`，检查后要么沉默要么回落到「有新版本时提醒」
  的占位文案，用户看不到检查时间与结果。验收：检查后显示「已是最新版本 +
  检查时间」；cooldown 场景（24h 内查过）同样显示最近一次结果。
- [ ] macOS 远控/虚拟机场景划词误发按键（2026-11-19）：运行拾趣时在向日葵、
  微软远程桌面等远控客户端或 VMware 等虚拟机窗口里打开文件夹、点选录入框，
  对面机器会自动键入字符（两次操作出现 "cc"）。原因是兼容模式兜底在这类
  窗口里模拟 ⌘C，合成按键被转发到对面机器且修饰键在转发中丢失。已对输入
  转发客户端（远控：向日葵/ToDesk/TeamViewer/微软远程桌面/RustDesk/AnyDesk
  等；虚拟机：VMware/Parallels/VirtualBox/UTM 等）跳过 ⌘C 兜底。验收：
  远控/虚拟机会话内框选/双击不再向对面注入任何字符；本机其他应用的兼容
  模式取词不受影响。
