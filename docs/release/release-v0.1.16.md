## Added（新增）

- [x] 翻译服务注册表化 + 机翻厂商批量接入（issue #2；谷歌已拍板**仅密钥模式**）
  - 鉴权两类：单密钥 / appId+密钥签名式；LLM 厂商不单独配置，走 BYOK「AI 翻译」
  - 设置页「添加服务」流：选择服务商即添加并启用，行内开关随时停用（配置保留——
    用量耗尽先停不删）；凭据行内填写，.row-del 移除需二次确认且连凭据一起删净
    （停用才是保留配置的工具，两动作分工）；启用中的服务必填凭据未填不允许保存；
    添加入口用卡片底部内联 chips 面板（完整目录常驻、AI 翻译通用项始终可见，
    已添加置灰打勾）；存量百度/DeepL 密钥自动迁移，无需重新填写
  - 本批接入 7 家：谷歌、微软 Azure、有道、腾讯云、阿里云、火山引擎、彩云小译
  - 挂起：小牛（官网文档站 JS 渲染无法核实签名，按约定不猜测实现）、
    Amazon（SigV4 复杂且暂无用户诉求，有 issue 再做）
  - [x] 响应解析与展示保真：各服务结果正确解析进结果面板，按 API 返回形式
        展示（译文原样呈现、换行保留，纯文本不被误渲染）
  - 待办（发版前）：真机逐家验证（需各厂商真实密钥）；微软「数据区域」
        留空/填写两种形态
- [x] 模型服务添加预设化 + 双形态（issue #1：OpenAI Responses 形态）：添加入口
  出预设 chips（选厂商自动带出名称/地址/形态，只填密钥与模型名——刻意不预设
  模型名，厂商迭代快写死必过时），自定义保留手填全项；接口形态所有卡常驻可切
  （形态选择权在用户；预设含该形态地址则自动带出——不同形态端点前缀可能完全

  DeepSeek、豆包、智谱、Kimi、Qwen、小米 MiMo、SiliconFlow、OpenAI、xAI、
  OpenRouter
  - 待办（发版前）：Responses 形态需 OpenAI 官方密钥真机验证；chat 形态用
        任一国内厂商密钥回归

## Changed（变更）

- [x] 二级菜单 hover 驻留展开（三处入口同一套规则）：胶囊条 ⌄ 动作整个项
  （主按钮+⌄）停留 300ms 展开，快速路过不开、点击行为不变，已有浮层时划过
  其他动作即切；「更多」面板行 hover 即切（面板已是打开的菜单表面，无驻留
  延迟）；结果窗动作行同胶囊规则
- [x] 统一收起与守卫：光标离开整体区域 350ms 收起；拖拽中、点击、新选区不误触
- [x] 结果窗动作行单行收纳：窄窗口不再折行——放不下的尾部动作收进行尾
  「更多 N」，点开为动作行上方的胶囊堆（贴右缘）；带子选项的胶囊尾部 ‹ 向左
  展开横向 chips（垂直居中于该胶囊）；堆尺寸不随子菜单变化，超长堆内滚动；
  点 chip 执行并收起全部
- [x] 浮动条收纳面板行方向示能：带行侧菜单的行首 › 指向实际弹出方向（贴屏幕
  右缘镜像为 ‹）；Obsidian 三个目标（笔记/任务/卡片）改为行侧横向 chips，
  服务/引擎菜单保持竖排列表
- [x] 悬浮操作层反色墨面（双主题）：结果窗 ⌄ 子菜单、胶囊堆与行侧 chips 用
  反色胶囊（亮色主题墨底白字、暗色主题近白底墨字），hover 点亮品牌靛——
  叠在正文上不透字、与被遮挡文字清晰分层；macOS / Windows 双平台
- [x] 二级菜单动效整体化（2026-10-20 定稿）：槽位 chips / 胶囊堆 / 行侧 chips
  统一「一个物体整体浮现/收拢」——一次运动入场，纯收起与切换短淡出（执行
  动作仍即时收起，不抢结果区的戏）；逐颗级联废弃（读作排队蹦出、节奏拖沓）
- [x] 划词设置页自动保存：动作开关、拖拽排序、自定义动作编辑即时落盘，
  页面级「保存更改」按钮移除（其余页面保留保存钮）

## Fixed（修复）

- [x] 网页表格内拖选/双击文字不弹胶囊（2026-10-21）：Chromium 把网页表格暴露
  为 AXTable→AXRow→AXCell，表格文字的拖选起点命中行项族角色、被非文本表面
  闸整链拦截。闸门新增差分例外——按下时留选区基线，松手后出现按下时不存在
  的新选区才放行（遗留选区不背书、基线缺失/复核失败仍拦截），拖表格行换位
  等控件手势不受影响；验收：浏览器文档页表格内拖选一行文字与双击表格单词，
  胶囊弹出且内容正确
- [x] 服务全停用/依赖缺失的动作仍占位（点击报错）：统一显示闸——动作开关 且
  依赖配置可用才显示，翻译看启用服务列表、搜索看启用引擎列表、AI 动作
  （解释/总结/自定义）看默认模型可用性、Obsidian 看 vault；胶囊/溢出面板/
  结果窗动作行同一套闸
- [x] Windows 结果窗点「钉图」全应用冻结（所有窗口无响应、钉图永不出现）：
  钉图窗口改为非主线程创建，立即出现且加载期间其余功能正常
- [x] 部分机型（如 Windows on ARM）浮动条与弹层呈直角矩形：恢复透明底自绘
  圆角，所有 Windows 机型正常；系统会裁圆角的机型保持系统平滑裁切
- [x] 结果窗在非拖拽期间残留不透明方角背景：防闪守卫只在拖拽中生效，拖拽
  结束即恢复圆角
- [x] 流式进行中打开服务菜单把译文压成一条：菜单收起后结果区必能恢复整窗高度
- [x] 自定义动作编辑丢字/保存旧 prompt（快速输入与中文 IME 组合期触发）；同一
  加固覆盖模型服务字段、prompt 覆写、搜索引擎与翻译凭据
