## Changed（变更）

- [ ] 内置 AI 提示词随界面语言（2026-11-07，原第二步提前）：翻译 / 解释 /
  总结 / 智能提取四个内置提示词出中英两套，默认展示、编辑回落与「恢复默认」
  均取当前界面语言那套；翻译输出标记【译文】/【要点】两套语言下保持原样
  （结果窗解析依据）。用户自定义提示词不受语言切换影响。
  验收：界面切英文后提示词页四个动作的默认内容为英文、恢复默认回英文版；
  切回中文同理；翻译结果窗分层（译文/要点）在英文界面下正常

- [ ] AI 动作输出语言跟随界面语言（2026-11-07，原第三步提前）：翻译 / 解释 /
  总结的目标（输出）语言不再写死中文规则，改为跟随界面语言——界面中文输出
  中文、界面英文输出英文；翻译在原文已是目标语言时在中英之间取另一种。
  机器翻译服务（百度/DeepL 等）方向同规则（原先按文本内容中↔英判定）。
  提示词以 {lang} 占位符表达，设置页可见原文、发送时按界面语言解析
  （与 {date} 同一先例，保持所见即所发）；用户自定义提示词不受影响。
  验收：界面切英文后翻译/解释/总结输出英文，切回中文输出中文；提示词页
  默认展示含 {lang} 原文，自定义提示词行为不变
