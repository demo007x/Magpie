# 品牌VI设计系统

## 一、VI设计流程

```
品牌定位 → 核心概念 → 视觉转化 → 系统构建 → 应用延展
```

### 1. 品牌定位
| 维度 | 问题 | 输出 |
|------|------|------|
| 使命 | 品牌存在的意义？ | 使命宣言 |
| 愿景 | 品牌想成为什么？ | 愿景描述 |
| 价值观 | 品牌坚守的原则？ | 价值主张 |
| 个性 | 品牌像什么样的人？ | 人设画像 |
| 定位 | 在用户心智中的位置？ | 差异化定位 |

### 2. 核心概念
- 关键词提取（3-5个）
- 视觉隐喻构思
- 情绪板(Mood Board)制作

### 3. 视觉转化
- Logo设计（图形/字标/组合）
- 色彩系统（主色/辅色/点缀色）
- 字体系统（标题/正文/装饰）
- 图形语言（辅助图形/图标风格）

### 4. 系统构建
- Logo规范（正负形/最小尺寸/安全区）
- 色彩规范（色值/比例/禁忌）
- 字体规范（层级/搭配/字号范围）
- 组合规范（Logo与信息组合方式）

### 5. 应用延展
- 办公系统（名片/信纸/文件袋）
- 导视系统（门牌/指示牌/楼层图）
- 数字系统（网站/App/社交媒体）
- 营销系统（海报/包装/周边）

## 二、Logo设计类型

| 类型 | 特点 | 适用品牌 |
|------|------|---------|
| 图形标 | 无文字、纯图形 | 国际化品牌、强辨识度 |
| 字标 | 品牌名设计 | 名称独特、传播导向 |
| 组合标 | 图形+文字 | 初创品牌、完整表达 |
| 徽章标 | 封闭形状 | 传统行业、官方感 |
| 动态标 | 可变形态 | 数字品牌、年轻化 |

### Logo设计原则
1. **可识别：** 缩小到1cm仍能识别
2. **可延展：** 适配各种应用场景
3. **可记忆：** 简洁独特易于记忆
4. **可持久：** 10年后仍不过时

## 三、品牌色彩系统

### 色彩角色
| 角色 | 占比 | 功能 |
|------|------|------|
| 主色 | 60% | 品牌核心识别 |
| 辅色 | 30% | 丰富层次 |
| 点缀色 | 10% | 吸引注意/强调 |

### 行业色彩偏好
| 行业 | 偏好色彩 | 心理暗示 |
|------|---------|---------|
| 科技 | 蓝/黑/银 | 专业、创新 |
| 金融 | 蓝/金/黑 | 信任、稳健 |
| 餐饮 | 红/橙/黄 | 食欲、热情 |
| 健康 | 绿/蓝/白 | 自然、纯净 |
| 教育 | 蓝/绿/橙 | 成长、智慧 |
| 时尚 | 黑/白/金 | 高端、经典 |

## 四、品牌字体系统

### 字体层级
| 层级 | 用途 | 字重 | 字号范围 |
|------|------|------|---------|
| H1 | 主标题 | Bold/Black | 36-72pt |
| H2 | 副标题 | SemiBold | 24-36pt |
| H3 | 小标题 | Medium | 18-24pt |
| Body | 正文 | Regular | 14-16pt |
| Caption | 注释 | Light/Regular | 10-12pt |

### 中英文字体搭配
| 风格 | 中文 | 英文 |
|------|------|------|
| 传统典雅 | 思源宋体/方正书宋 | Playfair Display/Garamond |
| 现代简约 | 思源黑体/苹方 | Helvetica/Montserrat |
| 潮流年轻 | 站酷高端黑/优设标题 | Bebas/DIN |
| 文艺清新 | 方正清刻本悦/凌慧体 | Cormorant/Lora |

## 五、VI应用规范示例

### 名片
- 尺寸：90×54mm（标准）/ 90×50mm（窄版）
- Logo位置：左上角或居中
- 信息层级：姓名→职位→联系方式
- 留白：至少5mm边距

### 海报
- 主视觉占60-70%
- 信息层级：标题→副标题→正文→品牌
- Logo位置：右下角或底部居中
- 尺寸：A4(210×297)/A3(297×420)/60cm×80cm

### 社交媒体
| 平台 | 头像 | 封面 |
|------|------|------|
| 微信公众号 | 正方形Logo | 900×383px |
| 微博 | 正方形Logo | 920×300px |
| 小红书 | 正方形Logo | 1242×1660px（笔记封面） |
| 抖音 | 正方形Logo | 1125×633px |

## 六、品牌VI自检清单

- [ ] Logo在黑白模式下可识别
- [ ] Logo缩小到20px仍清晰
- [ ] 色彩在不同设备显示一致
- [ ] 字体在Mac/Win都有替代方案
- [ ] 应用规范覆盖主要场景
- [ ] VI手册易于理解和执行
