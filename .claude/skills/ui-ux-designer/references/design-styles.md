# 设计风格百科

## 一、当代流行风格

### 🌃 赛博朋克 Cyberpunk
| 元素 | 特征 |
|------|------|
| 色彩 | 霓虹紫/电光蓝/激光粉/荧光绿，高对比度 |
| 字体 | 故障风、像素化、科幻感无衬线 |
| 图形 | 电路纹理、全息投影、城市天际线 |
| 氛围 | 高科技+低生活、反乌托邦、未来都市感 |
| 应用 | 游戏、音乐节、潮牌、科技产品 |
| 案例 | 《银翼杀手》《赛博朋克2077》|

### 🏠 诧寂风 Wabi-Sabi
| 元素 | 特征 |
|------|------|
| 色彩 | 大地色/灰褐/米白/墨绿，低饱和度 |
| 材质 | 原木、石材、亚麻、陶土 |
| 形态 | 不完美、不对称、留白、自然肌理 |
| 氛围 | 朴素、安静、岁月痕迹、东方禅意 |
| 应用 | 家居、茶品牌、高端酒店、日式美学 |
| 案例 | 无印良品、安藤忠雄建筑 |

### 🏗️ 包豪斯 Bauhaus
| 元素 | 特征 |
|------|------|
| 色彩 | 红/黄/蓝三原色 + 黑白灰 |
| 形态 | 几何抽象、功能至上、少即是多 |
| 字体 | 无衬线、网格系统、不对称排版 |
| 氛围 | 理性、工业化、民主设计 |
| 应用 | 建筑、家具、品牌系统、教育 |
| 案例 | 宜家、迪特·拉姆斯设计 |

### 🎨 孟菲斯 Memphis
| 元素 | 特征 |
|------|------|
| 色彩 | 高饱和撞色、粉紫+亮黄+电光蓝 |
| 图形 | 几何图形、波浪线、三角形、圆点 |
| 氛围 | 俏皮、叛逆、后现代、反极简 |
| 应用 | 包装、时尚、儿童产品、创意海报 |
| 案例 | 80年代后现代家具、AJ海报 |

### ✨ 极简主义 Minimalism
| 元素 | 特征 |
|------|------|
| 色彩 | 单色或双色，大量留白 |
| 形态 | 纯粹几何、负空间、隐藏功能 |
| 字体 | 无衬线、细线条、大字间距 |
| 氛围 | 宁静、高端、克制、永恒 |
| 应用 | 奢侈品、科技品牌、高端家居 |
| 案例 | Apple、Jil Sander、Dieter Rams |

### 🌿 新自然主义 Neo-Natural
| 元素 | 特征 |
|------|------|
| 色彩 | 森林绿/大地棕/天空蓝/阳光黄 |
| 材质 | 木材、藤编、棉麻、植物元素 |
| 形态 | 有机曲线、仿生形态、流动感 |
| 氛围 | 治愈、可持续、环保、返璞归真 |
| 应用 | 健康、母婴、有机食品、生活方式 |

### 🎭 蒸汽波 Vaporwave
| 元素 | 特征 |
|------|------|
| 色彩 | 粉紫渐变、青绿、霓虹 |
| 图形 | 古希腊雕塑、棕榈树、Windows 95窗口、动漫 |
| 字体 | 全角字符、日文片假名、故障效果 |
| 氛围 | 怀旧、讽刺、消费主义批判、网络美学 |
| 应用 | 音乐封面、潮流周边、网络文化 |

### 🔮 Y2K 千禧风
| 元素 | 特征 |
|------|------|
| 色彩 | 银色、金属粉、冰蓝、全息色 |
| 图形 | 液态金属、星球、外星人、矩阵代码 |
| 字体 | 气泡字、立体字、数字感 |
| 氛围 | 未来感、太空时代、科技乐观主义 |
| 应用 | 时尚、音乐、美妆、年轻品牌 |

## 二、经典风格体系

| 风格 | 时代 | 核心理念 | 代表人物 |
|------|------|---------|---------|
| 维多利亚 | 19世纪 | 装饰繁复、浪漫主义 | William Morris |
| 新艺术运动 | 1890-1910 | 自然曲线、手工艺 | Mucha、Gaudí |
| 装饰艺术 Art Deco | 1920-1940 | 几何对称、奢华感 | Cassandre |
| 瑞士国际主义 | 1950-1970 | 网格系统、无衬线 | Müller-Brockmann |
| 波普艺术 Pop Art | 1960s | 大众文化、高饱和 | Andy Warhol |
| 解构主义 | 1980s- | 破碎、非线性、反秩序 | David Carson |

## 三、风格选择指南

| 品牌调性 | 推荐风格 | 慎用风格 |
|---------|---------|---------|
| 科技创新 | 极简、赛博、Y2K | 维多利亚、乡村风 |
| 高端奢华 | 极简、诧寂、Art Deco | 孟菲斯、蒸汽波 |
| 年轻潮流 | 赛博、Y2K、孟菲斯 | 极简、诧寂 |
| 自然健康 | 新自然主义、诧寂 | 赛博、蒸汽波 |
| 文化艺术 | 新艺术、解构主义 | 极简、孟菲斯 |
| 复古怀旧 | 蒸汽波、维多利亚 | Y2K、赛博 |

## 四、风格融合技巧

### 赛博 + 东方 = 「赛博国潮」
- 霓虹色彩 + 传统纹样
- 科技字体 + 书法元素
- 案例：李宁「悟道」系列

### 包豪斯 + 诧寂 = 「理性禅意」
- 几何形态 + 自然材质
- 功能主义 + 不完美美学
- 案例：深泽直人设计

### 极简 + 新自然 = 「有机极简」
- 克制形式 + 有机曲线
- 单色调 + 自然肌理
- 案例：Nendo工作室
